# 能力边界

本文逐项说明 QingCue（轻词）能做什么、在什么条件下**不保证**，以及哪些部分属于实验性。
所有描述均以已实现范围为限，不替代真实验收结论；未验证项统一列在 [TESTING.md](TESTING.md)。

阅读约定：

- **已实现**：代码路径存在且自动化检查覆盖。
- **有条件**：在特定环境或朗读方式下才成立，超出条件不保证。
- **实验性**：方向已实现，但效果依赖场景，不作为稳定承诺。
- **未验证**：尚无真人 / 真机证据。

## 1. 语音跟随

**已实现。** 系统从输入设备持续取音，本地识别出与稿件对应的文本，据此推动高亮与滚动；不需要手动翻页或外接踏板。

**不保证的情况：**

- 环境噪声接近或高于朗读音量，或多人同时说话。
- 麦克风距离过远、增益过低，或设备被系统独占。
- 朗读内容与稿件不一致（自由发挥、插入大段稿件外内容）。
- 方言、口音、专业术语密集且不在模型词表覆盖范围内。
- 中英混读时的临时切换（双语能力存在，但切换处的跟随不做强保证）。

## 2. 自适应语速

**已实现，有条件。** 系统根据已识别的朗读进度估计当前语速，并在识别结果之间保持画面平滑，使高亮不因识别事件的稀疏而停顿。

**不保证的情况：**

- 语速突变（例如突然加速数倍）后的短时间内可能出现滞后或轻微超前，随后自行收敛。
- 长时间完全无声（默读、走台）时，画面只做有限的惯性延续，不会凭时间无限推进。
- 识别结果尚未稳定时，句内位置可能与真实开口位置存在可见偏差。

## 3. 语速趋势呈现

**实验性。** 界面可将近期朗读节奏以趋势形式呈现，帮助演讲者感知自己是在加速还是放慢。

- 趋势是对已发生朗读的**估计**，不是精确测量，不应作为演讲节奏的量化依据。
- 趋势的可读性依赖屏幕尺寸与观看距离；小窗口下辨识度下降。
- 该项属于辅助信息，不参与跟随决策。

## 4. 停顿、重复、回读与跳读

| 行为 | 支持情况 | 说明 |
| --- | --- | --- |
| 正常停顿 | 支持 | 停顿期间画面停在当前句，不因静默自动跳句 |
| 重复朗读同一句 | 支持 | 重复内容视为仍在当前句内，不会把进度推到更后面 |
| 回读（读回上一句） | 支持，有条件 | 系统识别为「已读内容」，保持当前位置；跨段落大幅回读不做强保证 |
| 跳读（跳过整句/整段） | 支持，有条件 | 识别到稿件后文内容时会向前收敛；跳读跨度过大时可能短暂停留再追上 |
| 口误 / 改口 | 支持，有条件 | 以稿件为准做容错对齐，口误不会把进度带偏；连续大量口误时可能停在原位等待更多证据 |
| 稿件外自由发言 | 不支持保证 | 系统不会因稿件外内容而推进；长时间离线发言后可能停在原处 |

以上行为均有自动化检查覆盖，但**真人朗读下的实际表现尚未验收**（见 TESTING.md）。

## 5. 换句准备

**已实现。** 系统在当前句尚未读完时即准备后续内容，使跨句切换不产生额外等待。

**边界：**

- 依赖稿件已正确分段；单句极长或段落结构异常时，换句流畅度下降。
- 该机制只影响切换流畅度，不改变进度推进规则。

## 6. 扫描视觉引导

**已实现，有条件。** 界面提供固定的视觉参照与连续滚动，使当前句始终处于可读区域，并以视觉引导提示阅读位置。

- 视觉参照是**显示层**的辅助，不代表朗读的可信程度或语音能量。
- 不同窗口尺寸、缩放比例与显示器 DPI 下的观感未做逐一验收。
- 视觉引导的强弱属于可调显示偏好，不影响跟随算法。

## 7. 定速提词（无语音模式）

**已实现。** 关闭语音跟随时，按设定节奏自动推进，仅依赖时间。

- 不需要任何识别模型，也不占用麦克风。
- 与真实朗读速度脱节属于该模式的固有特性，不属于缺陷。

## 8. 稿件与数据

**已实现。** 支持导入纯文本与 Markdown 稿件；稿件、设置与诊断数据保存在本机，不上传。

**边界：**

- 复杂排版（表格、嵌套列表、图文混排）不做保真还原，按纯文本语义处理。
- 稿件过长时的首屏加载与检索未做专门优化承诺。

## 9. 运行环境

**已实现。** Windows 10/11 x64，安装包自包含运行所需运行时；无需预装开发环境或额外系统组件。

**不保证的情况：**

- 企业环境中被策略限制的 WebView2 运行时（未做企业策略验收）。
- 多显示器、不同 DPI 混合桌面下的窗口行为（未验证）。
- 实体手机 / 遥控器等外设的联动（未验证）。
- 断网状态下的首次模型获取（首次使用需要能获取模型；已具备模型后可离线）。

## 10. 明确的非目标

以下不在当前版本的设计目标内：

- 多人协作、云端同步、账号体系。
- 自动生成讲稿、改写稿件或语义问答。
- 将朗读内容上传、转写归档或用于训练。
- 对朗读质量（音量、情感、节奏）做评价或打分。
