# 能力边界

本文逐项说明 QingCue（轻词）能做什么、在什么条件下**不保证**，以及哪些部分尚未验证。
所有描述以已实现范围为限，不替代真实验收结论；未验证项统一列在 [TESTING.md](TESTING.md)。

状态统一使用三档：

- **已实现**：功能存在，且自动化检查覆盖。
- **条件支持**：在特定前提下成立（例如首次需联网获取模型、设备可用），超出条件不保证。
- **未验证**：尚无真人 / 真机证据，不作为承诺。

## 1. 语音跟随

**已实现；语音模型为条件支持。** 系统从输入设备持续取音，在本机完成流式识别，并据此推动高亮与滚动，
不需要手动翻页或外接踏板。识别运行时为 sherpa-onnx，模型为 Qwen3-ASR 0.6B INT8。

**条件支持：** 首次使用需联网获取模型，完成后可离线运行；定速提词不依赖模型。

**不保证的情况：**

- 环境噪声接近或高于朗读音量，或多人同时说话。
- 麦克风距离过远、增益过低，或设备被系统独占。
- 朗读内容与稿件不一致（自由发挥、插入大段稿件外内容）。
- 方言、口音、专业术语密集且超出模型覆盖范围。
- 中英混读时的临时切换（双语能力存在，但切换处的跟随不做强保证）。

## 2. 逐词滑动与视觉跟随

**已实现。** 高亮以词为单位向前移动，画面连续滚动，前后文始终留在视野里。

**边界：**

- 滚动是有界跟随：高亮接近可读区边缘时才移动，不会因快读而剧烈晃动。
- 不同窗口尺寸、缩放比例与显示器 DPI 下的观感未做逐一验收（见 [TESTING.md](TESTING.md)）。

## 3. 语速趋势

**条件支持。** 界面可将近期朗读节奏以趋势形式呈现，帮助演讲者感知自己在加速还是放慢。

- 趋势是对已发生朗读的**估计**，不是精确测量，不应作为节奏的量化依据。
- 可读性依赖屏幕尺寸与观看距离，小窗口下辨识度下降。
- 该项属于辅助信息，不参与跟随决策。

## 4. 停顿、重复、回读与跳读

| 行为 | 状态 | 用户可见表现 |
| --- | --- | --- |
| 正常停顿 | 已实现 | 画面停在当前句，不因静默自动跳句 |
| 重复朗读同一句 | 已实现 | 重复内容视为仍在当前句内，不会把进度推到更后面 |
| 回读（读回上一句） | 条件支持 | 识别为已读内容，保持当前位置；跨段落大幅回读不做强保证 |
| 跳读（跳过整句 / 整段） | 条件支持 | 读到后文内容时会向前赶上；跨度很大时可能短暂停留再追上 |
| 口误 / 改口 | 条件支持 | 以稿件为准做容错，口误不会把进度带偏；连续大量口误时倾向停在原位 |
| 稿件外自由发言 | 未验证 / 不保证 | 系统不会因稿件外内容而推进；长时间离稿发言后可能停在原处 |

以上行为均有自动化检查覆盖，但**真人朗读下的实际表现尚未验收**。

## 5. 跨句连续

**已实现。** 当前句读完后，高亮前移、画面滚动到下一句，底部趋势同步更新；跨句切换不产生额外等待。

- 依赖稿件已正确分段；单句极长或段落结构异常时，衔接的流畅度下降。
- 跨句准备只影响切换流畅度，不改变推进判断本身。

## 6. 悬浮提词与窗口

**已实现。** 提供独立置顶的悬浮提词窗，位置与大小可自行调整。

- 悬浮窗与主窗口的摆放不互相遮挡由用户自行控制。
- 多显示器、混合 DPI 下的窗口行为未验证。

## 7. 定速提词（无语音模式）

**已实现。** 关闭语音跟随时，按设定节奏自动推进，仅依赖时间。

- 不需要任何识别模型，也不占用麦克风。
- 与真实朗读速度脱节属于该模式的固有特性，不属于缺陷。

## 8. 稿件与数据

**已实现。** 支持导入纯文本与 Markdown 稿件；稿件、设置与诊断数据保存在本机，不上传。

**边界：**

- 复杂排版（表格、嵌套列表、图文混排）不做保真还原，按纯文本语义处理。
- 稿件过长时的首屏加载与检索未做专门优化承诺。

## 9. 运行环境

**已实现。** Windows 10 / 11 x64，安装包自包含 .NET 8 运行时与固定版 WebView2，无需预装开发环境。

**条件支持 / 未验证：**

- 企业策略限制下的 WebView2 运行时未做验收。
- 多显示器、不同 DPI 混合桌面下的窗口行为未验证。
- 实体手机、遥控器等外设联动未验证。
- 断网状态下的首次模型获取（首次使用需能获取模型；已具备模型后可离线）。

## 10. 明确的非目标

以下不在当前版本的设计目标内：

- 多人协作、云端同步、账号体系。
- 自动生成讲稿、改写稿件或语义问答。
- 将朗读内容上传、转写归档或用于训练。
- 对朗读质量（音量、情感、节奏）做评价或打分。
