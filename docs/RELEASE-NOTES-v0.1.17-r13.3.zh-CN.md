# 轻词 QingCue 0.1.17 + r13.3 发布说明（简体中文）

本页为英文 Release 正文的中文版本，便于中文用户阅读。英文页面：[Release v0.1.17-r13.3](https://github.com/ShowKang/QingCue-Downloads/releases/tag/v0.1.17-r13.3)。

## 概述

轻词 QingCue 是一款 Windows 桌面自然语音跟随提词器。你按自己的节奏说话，画面随声音前进，不必低头找行、手动翻页或在句尾寻找下一句。本版本为安装与分发修订，提词与语音跟随能力保持不变。

## 本次更新

- **许可与版权**：补齐第三方组件许可原文与版权说明，随安装包分发。
- **文件完整性**：提供 SHA-256 校验文件，便于核对下载内容。
- **溯源信息**：完善安装包溯源信息，便于核对构件与版本。
- **兼容性**：系统要求与安装方式不变，支持覆盖升级。
- **数据保留**：升级后稿件、设置与本地模型按既有机制保留。

## 核心功能

- 自然语音跟随：按真实语速推进，无需踏板或遥控器。
- 词级高亮：高亮以词为单位移动。
- 连续文本跟随：跨句滚动连贯，阅读位置稳定。
- 悬浮提词窗口：独立置顶，可与录制或直播软件并排。
- 稿件管理：纯文本与 Markdown 导入，文件夹归类。
- 本地语音识别：语音在本机处理，音频不上传。
- 固定语速提词：无需模型与麦克风。

## 安装

1. 在 [Release 页面](https://github.com/ShowKang/QingCue-Downloads/releases/tag/v0.1.17-r13.3) 下载 `QingCue-0.1.17-r13.3-win-x64.msi` 与 `SHA256SUMS.txt`。
2. 核对 SHA-256，详见 README 的校验章节。
3. 双击 MSI 按向导安装，或执行 `msiexec /i QingCue-0.1.17-r13.3-win-x64.msi`。

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11，64 位 |
| 架构 | x64 |
| 运行环境 | 安装包自包含，无需另装运行时或 VC++ 运行库 |
| 磁盘 | 应用约 1 GB；主语音模型另需约 900 MB |
| 网络 | 仅首次下载模型时需要 |

安装包内置两套小型入门模型（合计约 101.7 MB）；主语音模型首次在应用内下载（约 900 MB），完成后可离线使用。

## 隐私

- 语音识别在本机完成，音频不上传、不留存、不用于训练。
- 稿件、设置与模型保存在本机，无需账号，不存在云端同步。
- 主模型就绪后，断网不影响提词与语音跟随。
